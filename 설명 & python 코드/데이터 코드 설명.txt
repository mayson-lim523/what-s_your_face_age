이 비율을 맞추기 위한 코드로는 remove.py및 division.py로 구성이 되었는데 이는 파일에 첨부할 예정이다.
간단하게 설명한다면 remove.py의 경우는 10대~30대의 데이터 비율이 맞지 않아 데이터 비율을 맞추기 위해 이미지를 제거한 코드이며, division.py의 경우는 각각의 데이터셋의 데이터를 총합 하여 test, validation, train으로 나눈 코드이다.

각각의 데이터셋을 확인 하였을 때 AFAD데이터의 경우만 나이대별로 상세하게 라벨링이 되어있었고, 다른 데이터의 경우는 csv, 이미지의 이름으로 라벨이 구분되어 있어 이를 구분하기 위해 첨부한 코드를 사용하였다.

fairface : fairface_val.py, fairface_train.py
fairface의 경우 데이터셋이 validation, traind으로 총 2개가 구성되어 코드를 2개 작성하였으며, csv파일을 이용해 라벨링 되어있는 이미지의 이름과 라벨링 되어있는 나이를 토대로 분류를 하였다.

AAF : AAF.py
AAF의 경우는 csv파일이 존재하지 않았으며 파일 내부에 있는 original images즉 원천데이터를 이용하는 방식으로 하였다.
원천데이터의 이미지 이름이 xxxxxAxx라 적혀있는데 이 뒤에있는 Axx의 경우가 나이를 의미하며 앞은 이미지의 고유 번호이기 때문에 Axx로 나이를 분류하는 코드를 토대로 분류하는 방식으로 설정하였다.

UTK : UTK.py
UTK의 경우 x_x_x_xxxxx로 되어있는데 이 중 가장 앞에있는 x가 나이를 의미하며, 이 제일 앞자리를 토대로 나이를 분류하는 코드를 작성하였다.

또한 비율을 분류하는 코드는 per.py를 작성 하였는데, 이는 test, validation, train파일을 읽고 내부의 데이터 수를 체크한 뒤 그것을 토대로 비율을 보여주는 코드이다.
