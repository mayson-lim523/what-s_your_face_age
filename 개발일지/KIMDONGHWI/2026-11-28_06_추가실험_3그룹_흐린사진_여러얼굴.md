## 2. 코드 변경 (ConvNeXt/code, ResNet50/code 공통)

- `common.py`
  - `AGE_GROUPS` 환경변수(기본 7, `set AGE_GROUPS=3`이면 3그룹), `GROUP_OF_BAND = [0, 0, 1, 1, 1, 1, 2]`
  - `build_transforms(train, augment=True, blur=False, paste_paths=None, paste_p=0.0)`: 흐림 증강, 얼굴 붙이기 증강 추가
  - `paste_face()`, `RandomPasteFace`: 다른 학습 사진의 가운데 70%를 폭의 30~45%로 줄여 구석에 붙임 (0~30%는 사진 밖)
- `step4_train.py`: `--blur-aug`, `--paste-aug P` 추가, 라벨 범위 확인, `best.pt`에 `num_classes` 저장
- `step5_evaluate.py`: 체크포인트의 `num_classes`와 지금 설정이 다르면 멈춤
- 옵션을 주지 않으면 이전과 똑같이 동작한다.

## 3. 오류와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| `size mismatch [7, 768] vs [3, 768]` | 3그룹 학습 후 `AGE_GROUPS=3`이 cmd 창에 남아 있음 | `set AGE_GROUPS=7` 또는 새 cmd 창 |
| `No module named facenet_pytorch` | MTCNN 패키지 없음 | `pip install facenet-pytorch --no-deps` (torch 버전을 바꾸지 않도록) |
| `No module named requests` | `--no-deps`로 설치해서 빠짐 | `pip install requests` |
| `eval_paste.py`를 찾을 수 없음 | 받은 zip을 안 풀었음 | `tar -xf "%USERPROFILE%\Downloads\paste_update.zip" -C C:\age_project` |

## 4. 배운 점

- 7개 분류의 오류는 대부분 바로 옆 나이대라서, 크게 묶으면(3그룹) 정확도가 30%p 가까이 오른다. 따로 학습할 필요 없이 묶어 채점만 해도 거의 같다.
- 증강은 "모델이 실제로 겪을 변화"를 정확히 흉내 낼 때만 효과가 있다. 인공 흐림에는 효과가 있었지만 원래 흐린 실제 사진에는 효과가 없었다.
- 여러 얼굴 문제는 평가 때 다른 얼굴을 가리는 것보다 학습 때 그런 사진을 보여 주는 것이 효과적이었다.
