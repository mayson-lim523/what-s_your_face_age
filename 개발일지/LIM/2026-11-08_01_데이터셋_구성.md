## 3. 최종 코드 (프로그램 4-1)

```python
#프로그램 4-1 얼굴 나이대 데이터 셋 구성하기

import torch
import os
from torchvision import datasets, transforms
from torch.utils.data import DataLoader, Subset

DATA_DIR = "data"
IMG_SIZE = 224
BATCH_SIZE = 32
SEED = 42

MEAN = (0.485,0.456,0.406 )
STD = ( 0.229, 0.224, 0.225)

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
print("using device:", device)

train_transform = transforms.Compose([
    transforms.Resize(IMG_SIZE),          # 짧은 변을 224로 (비율 유지)
    transforms.CenterCrop(IMG_SIZE),      # 가운데 224×224
    transforms.RandomHorizontalFlip(p=0.5),                # 좌우 반전
    transforms.RandomRotation(degrees=10),           # ±10도 회전
    transforms.ColorJitter(brightness=0.2),       # 밝기 변화
    transforms.ToTensor(),                     # PIL 이미지 → 텐서 (0~1)
    transforms.Normalize(MEAN, STD),
    ])

# 검증용: 증강 없이 크기 맞추기 + 텐서 + 정규화만
val_transform = transforms.Compose([
    transforms.Resize(IMG_SIZE), 
    transforms.CenterCrop(IMG_SIZE),
    transforms.ToTensor(),
    transforms.Normalize(MEAN, STD),
])

# ---------- dataset ----------
train_dataset = datasets.ImageFolder(
    root=os.path.join(DATA_DIR, "training"),
    transform=train_transform,
)
val_dataset = datasets.ImageFolder(
    root=os.path.join(DATA_DIR, "validation"),
    transform=val_transform,
)

print(train_dataset.class_to_idx)          # 라벨 순서 확인
print(len(train_dataset), len(val_dataset))

# ---------- 소규모 부분집합 ----------
N_TRAIN = 100      # 1단계: 100장 과적합 테스트 → 나중에 늘리기
N_VAL   = 100

g = torch.Generator().manual_seed(SEED)    # 시드 고정 → 매번 같은 부분집합
train_idx = torch.randperm(len(train_dataset), generator=g)[:N_TRAIN].tolist()
val_idx   = torch.randperm(len(val_dataset), generator=g)[:N_VAL].tolist()

train_subset = Subset(train_dataset,train_idx)
val_subset   = Subset(val_dataset,val_idx)

# ---------- dataloader ----------
train_loader = DataLoader(train_subset, batch_size=BATCH_SIZE, shuffle=True)
val_loader   = DataLoader(val_subset,   batch_size=BATCH_SIZE, shuffle=False)

images, labels = next(iter(train_loader))
print(images.shape)   # torch.Size([32, 3, 224, 224]) 이어야 정상
print(labels[:10])    # 0~6 사이 숫자들이 섞여 나와야 정상
print(images.mean().item(), images.std().item())  # 정규화됐으면 대략 0 근처, 1 근처
```

### 코드 설계 이유

| 부분 | 선택 | 이유 |
|---|---|---|
| 데이터 로딩 | `ImageFolder` | 폴더 이름이 라벨이라 교재 코드와 사용법이 거의 같다 |
| 텐서 변환 시점 | 학습 중 배치마다 (`transform`) | 미리 전부 변환하면 메모리가 부족하고(3만 장 기준 약 18GB), 증강이 매번 달라지지 않는다 |
| transform | train용 / val용 2개 | 증강은 학습 데이터에만 적용한다. 검증은 항상 같은 조건이어야 한다 |
| `Resize(224)` + `CenterCrop(224)` | 숫자 하나로 리사이즈 | 비율을 유지한다. `Resize((224,224))`는 얼굴이 찌그러질 수 있다. 지금 이미지는 모두 224라 안전장치 역할만 한다 |
| 증강 3종 | 좌우 반전, ±10° 회전, 밝기 ±20% | 발표 자료의 증강 계획과 맞춤 |
| `Normalize(MEAN, STD)` | ImageNet 평균·표준편차 | 발표 자료 계획과 맞춤. 상수로 한 곳에서 관리해서 4-5 시각화 때 재사용한다 |
| 부분집합 | `randperm` + 고정 시드 | ImageFolder는 클래스 순서로 정렬되어 있어서 `range(N)`으로 자르면 한 나이대만 뽑힌다 |
| testing 폴더 | 지금은 불러오지 않음 | 최종 평가 때 한 번만 사용한다 |
| 경로 | 상대 경로 `data/...` | 팀원 PC(Mac 포함)에서도 같은 코드로 돌아간다 |

## 5. 오류 및 수정 기록 (트러블슈팅)

| # | 문제 | 증상 / 원인 | 수정 |
|---|---|---|---|
| 1 | `import os` 누락 | `os.path.join` 사용 시 `NameError` | `import os` 추가 |
| 2 | `Subset` import 누락 | `NameError` | `from torch.utils.data import DataLoader, Subset` |
| 3 | `transforms.centerCrop` | 대소문자 오류로 `AttributeError` | `CenterCrop` (transform 이름은 대문자로 시작) |
| 4 | 경로에 `\` 그대로 사용 | `"C:\3th...\training"`에서 `\3`은 제어문자, `\t`는 탭, `\v`는 수직 탭으로 해석되어 경로가 깨짐 | 상대 경로 `os.path.join(DATA_DIR, "training")` 사용. 절대 경로가 필요하면 `r"..."` raw 문자열 사용 |
| 5 | `os.path.join(DATA_DIR, "C:\...")` | 두 번째 인자가 절대 경로이면 첫 번째 인자(`DATA_DIR`)가 무시됨 | 두 번째 인자에는 하위 폴더 이름만 넣기 |
| 6 | `DATA_DIR = "DATA"` | 윈도우는 대소문자를 구분하지 않아 돌아가지만, Mac/리눅스/Colab에서는 오류 | `"data"`로 실제 폴더명과 일치시킴 |
| 7 | val에 `training` 폴더 지정 | 에러 없이 돌아가서 알아채기 어려움. 검증 정확도가 부풀려져 과적합을 감지할 수 없음 | `validation`으로 수정 |
| 8 | train에 `testing` 폴더 지정 | 시험 데이터를 학습에 사용 → 최종 평가 결과를 믿을 수 없게 됨 | `training`으로 수정 |
| 9 | `Normalize`에 숫자를 직접 입력 | 위에서 정의한 `MEAN`, `STD`를 쓰지 않아 값이 두 곳에 존재 | `Normalize(MEAN, STD)`로 통일 |

**배운 점**

- `os.path.join(A, B)`에서 A는 기준 폴더, B는 그 안의 하위 폴더 이름이다.
- 윈도우 경로를 문자열로 쓸 때 `\`는 이스케이프 문자다. 상대 경로나 raw 문자열을 쓴다.
- 경로가 틀렸는데 에러가 나지 않는 경우(7, 8번)가 가장 위험하다. **데이터 개수를 출력해서 기대값과 비교**하는 습관이 필요하다.
- `device = torch.device(...)`는 장치를 **고르기만** 한다. 실제로 GPU를 쓰려면 모델과 데이터를 모두 `.to(device)`로 옮겨야 한다 (4-2, 4-4에서 적용).

### 시도했다가 뺀 것: `RandomErasing`

- `RandomErasing(p=0.5, scale=(0.02, 0.20))`을 `Normalize` 뒤에 추가했었다 (텐서에 적용하는 증강이라 위치는 맞음).
- 발표 자료의 증강 계획(반전·회전·밝기)에 없던 항목이라 비교 실험 3(증강 적용/미적용)에 영향을 준다. 또 주름이나 눈가처럼 나이 판단에 중요한 부위를 자주 가릴 수 있다.
- → 일단 제외했다. 나중에 추가 실험 조건으로 팀과 논의한다.
