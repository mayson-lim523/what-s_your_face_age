# 얼굴 나이대 분류 시연 코드 설명 및 수정 내역

두 파일은 같은 학습 모델을 사용하지만, 한 장의 사진에서 **누구의 얼굴을 잘라 모델에 넣는지**, **결과를 어떤 이미지로 보여 주는지**가 다르다. 아래 줄 번호는 함께 제공한 Python 파일 기준이다.

| 항목 | `app_blur_only_fixed.py` | `app_multi_only.py` |
|---|---|---|
| 분석 대상 | 기존 검출기가 선택한 가장 큰 얼굴 1개 | 여러 검출기의 후보를 합치고 중복을 제거한 얼굴 N개 |
| CNN·Grad-CAM 입력 | 선택한 얼굴의 선명한 원본 crop | 각 얼굴의 선명한 원본 crop |
| 기본 crop 범위 | 검출 상자 그대로 | 각 검출 상자에 학습 사진 기준 여백 적용 |
| 전체 사진 출력 | 선택 상자만 선명하고 나머지 영역은 블러 | 검출 상자와 얼굴 번호 표시 |
| Gradio 예측 결과 | 한 얼굴의 상위 3개 나이대·확률, Grad-CAM 한 장 | 얼굴별 1위 나이대·확률, crop과 Grad-CAM 갤러리 |

## 1. 두 파일이 공유하는 기존 처리

- **G-1 설정** — `parse_args()`에서 모델 이름, 가중치 경로, CPU/GPU, 포트, crop 여백, 점검용 이미지 경로를 읽는다. `BAND_NAMES`는 모델 출력 7개를 0–9세, 10대, 20대, 30대, 40대, 50대, 60세 이상 순서로 해석한다.
- **G-2 모델 로딩** — `load_model()`은 SmallCNN을 프로젝트의 학습 코드에서 불러온다. ResNet-50과 ConvNeXt-Tiny는 `timm.create_model(..., num_classes=7)`로 구조를 만들고 저장된 가중치를 채운다. 이후 모델을 지정한 장치로 옮기고 `eval()`로 설정한다. 위치는 블러 78행, 다중 83행이다.
- **G-3 얼굴 검출** — OpenCV Haar cascade가 흑백 사진에서 얼굴 위치를 찾는다. 검출 전에 사진 긴 변의 25%만큼 사방에 검은 테두리를 붙여, 화면 가장자리에 얼굴이 붙은 경우에도 검출할 공간을 확보한다. 검출 후에는 테두리 두께를 좌표에서 빼서 **원본 RGB 사진**에서 얼굴을 자른다.
- **G-4 나이대 예측** — `predict()`는 얼굴 crop에 학습 코드의 `val_transform`을 적용한다. 224×224로 크기를 맞추고 텐서 변환·정규화를 거친 뒤, `unsqueeze(0)`로 배치 차원을 추가한다. 모델 출력 7개에 softmax를 적용해 나이대별 확률을 반환한다. 위치는 블러 171행, 다중 219행이다.
- **G-5 Grad-CAM** — 예측 확률 계산에는 `torch.no_grad()`를 사용한다. Grad-CAM은 기울기가 필요하므로 별도 호출에서 같은 얼굴 crop을 전처리해 전달한다. `overlay(face, heat)`는 중요 영역을 해당 얼굴 위에 겹쳐 보여 준다.

## 2. 블러 전용 코드에서 수정한 부분

### G-3 · 한 얼굴을 고르고 원본에서 자르기 (104–150행)

기존 `detect_face()`의 선택 규칙은 116행부터 볼 수 있다. 기본 정면 → 다른 정면 검출기 → 옆얼굴 → 좌우 반전한 옆얼굴 순으로 시도한다. **처음으로 검출에 성공한 단계**에서 탐색을 멈추고, 그 단계의 상자 중 `w × h`가 가장 큰 하나를 고른다.

기존 단일 crop 처리를 `selected_face()`로 바꾸면서 두 값을 함께 반환하도록 했다.

| 반환값 | 내용 | 사용하는 곳 |
|---|---|---|
| `face` | 원본에서 잘라낸 RGB 얼굴 이미지 | CNN 예측, Grad-CAM 계산 및 합성 |
| `bounds` | 사진 경계 안으로 제한한 검출 상자의 왼쪽·위·오른쪽·아래 좌표 | 전체 사진에서 선명하게 복원할 위치 |

기본 `MARGINS`는 네 방향 모두 0으로 바꿨다. 기존 기본값은 턱 아래를 더 포함하는 등 검출 상자 밖까지 crop할 수 있었다. 이 버전에서는 양수 여백을 지정해도 crop이 검출 상자를 넘어가지 않는다. 음수 여백은 해당 방향을 안쪽으로 줄인다. **상자의 의미는 Haar가 검출한 직사각형**이므로, 상자 모서리에 원래 배경이 찍혔다면 그 픽셀도 crop에 들어간다.

### G-3 · 전체 사진 미리보기 생성 (154–159행)

`make_blur_preview(image, bounds)`를 추가했다. 이전 블러 코드에서는 얼굴 주변 일부만 잘라 흐린 이미지를 모델에도 전달했다. 현재 함수는 원본과 같은 크기로 전체 사진을 흐린 다음, 선택한 직사각형만 원본 픽셀로 복원한다.

```python
original = image.convert("RGB")
preview = original.filter(ImageFilter.GaussianBlur(radius=max(5, min(image.size) / 40)))
preview.paste(original.crop(bounds), bounds)
return preview
```

블러 반경은 사진의 짧은 변 길이의 1/40이며 최소 5픽셀이다. 다른 얼굴을 하나씩 찾아 흐릴 필요가 없다. 선택 상자 밖에 있는 모든 픽셀에 이미 블러가 적용됐기 때문이다.

### G-5 · CNN 입력과 화면 출력을 연결하는 부분 (192–216행)

```python
face, bounds = selected
probs = predict(model, face, device)
heat, _ = cam(val_transform(face).unsqueeze(0).to(device))
return probs, make_blur_preview(img, bounds), overlay(face, heat)
```

**202–203행의 두 호출에 들어가는 변수는 모두 `face`다.** 블러 이미지는 204행에서 화면의 두 번째 출력값을 만들 때 생성한다. 따라서 같은 얼굴 crop을 그대로 두고 블러 반경만 바꾸면 미리보기만 달라진다. 다만 기존 앱과 예측값을 비교할 때는 기본 crop 여백 변경이 결과에 영향을 줄 수 있다. 얼굴 검출에 실패하면 경고를 띄우고 세 출력을 모두 비운다.

**명령줄 점검도 수정했다(233–244행).** `--image`를 주면 같은 `selected_face()`로 자른 얼굴 한 개의 좌표, 입력 crop 크기, 상위 3개 나이대와 확률을 출력한다.

## 3. 다중 얼굴 전용 코드에서 수정한 부분

### G-3 · 얼굴 한 개를 반환하던 검출을 여러 얼굴 목록으로 변경 (129–176행)

1. `detect_faces_all()`은 기존 Haar 검출기 구성을 사용하되, 한 검출기가 얼굴을 찾아도 계속 진행한다. 덕분에 기본 정면 검출기가 한 사람을 찾은 뒤에도 옆얼굴 검출기가 다른 사람을 찾을 수 있다.
2. 좌우 반전한 사진에서 찾은 상자는 `x = 반전 사진 너비 - x - w`로 가로 위치를 되돌린다. 검은 테두리를 뺀 뒤 상자가 원본 사진을 벗어난 부분을 잘라낸다.
3. 여러 검출기가 같은 얼굴을 찾을 수 있으므로 `_face_box_iou()`로 두 상자의 **교집합 면적 ÷ 합집합 면적**을 계산한다. 면적이 큰 후보부터 확인해, 이미 선택한 상자 중 하나와 IoU가 **0.35 이상**이면 그 후보는 제외한다. 이 값은 상자의 위치 중복을 판단하는 기준이다. 서로 다른 얼굴도 많이 겹쳐 찍히면 하나가 제외될 수 있다.
4. 남은 상자를 가로 중심 좌표가 작은 순으로 정렬한다. 따라서 `Face 1`은 사진에서 가장 왼쪽 중심을 가진 검출 상자다. 번호는 사진마다 새로 붙인다.

### G-3 · 얼굴별 crop과 표시용 상자 생성 (179–206행)

`detect_and_crop_all()`은 각 검출 상자에 기존 여백 `(0.02, -0.065, 0.02, 0.105)`를 적용한다. 예를 들어 100×100 상자라면 정수 변환 후 왼쪽·오른쪽을 각각 2픽셀 넓히고, 위쪽은 6픽셀 안쪽에서 자르며, 아래쪽은 10픽셀 더 포함한다. 결과는 `[(얼굴 crop, 검출 상자), ...]` 목록이다.

`draw_face_boxes()`는 원본 사진의 복사본에 초록색 사각형과 `Face 1`, `Face 2` 등의 번호를 그린다. **초록색 상자는 검출 위치**를 나타내며, 실제 CNN 입력 범위에는 위의 여백이 반영된다. 번호와 사각형은 얼굴을 자르고 예측한 뒤 표시용 사진에만 그린다.

### G-5 · 검출된 얼굴 수만큼 예측하고 출력 (239–287행)

254행의 `for index, (face, box) in enumerate(faces, start=1)`가 기존 단일 예측을 바꾼 부분이다. 예를 들어 얼굴이 세 개 검출되면 반복문이 세 번 실행된다. 매번 해당 인물의 crop으로 `predict()`와 Grad-CAM을 각각 호출한다. 세 얼굴 모두 드롭다운에서 선택한 동일한 모델을 사용한다.

| Gradio 출력 | 담기는 내용 |
|---|---|
| `boxed_image` | 얼굴 위치와 번호를 표시한 전체 사진 |
| `face_gallery` | 사람별 원본 crop과 번호·1위 나이대·확률 |
| `cam_gallery` | 같은 번호와 예측 라벨을 붙인 사람별 Grad-CAM |
| `summary` | 검출 개수와 얼굴별 1위 나이대·확률 목록 |

얼굴이 0개면 경고와 검출 실패 문구를 표시하고 두 갤러리를 비운다. **명령줄 모드(304–314행)**도 모든 얼굴을 순회하며, 이때는 사람마다 좌표, crop 크기, 상위 **3개** 나이대와 확률을 출력한다.

## 4. 실행 방법

두 파일을 기존 프로젝트의 `시연/app.py`와 같은 폴더에 놓는다. 두 앱은 각각 실행할 수 있으며, 기존 프로젝트의 `시연/gradcam.py`, `작은CNN/CNN_4layers_unified.py`, 학습 가중치를 사용한다. 프로젝트 최상위 폴더에서 원하는 명령 하나를 실행한다.

```powershell
# 블러 전용 화면
python .\시연\app_blur_only_fixed.py

# 다중 얼굴 전용 화면 (두 화면을 함께 띄울 경우 다른 포트 사용)
python .\시연\app_multi_only.py --port 7861

# ResNet-50으로 단체 사진 한 장 점검
python .\시연\app_multi_only.py --model resnet50 --image ".\단체 사진.jpg"
```

기본 시작 모델은 `small_cnn`이다. 시작 시 선택한 모델의 가중치가 필요하다. Gradio에서는 업로드하거나 웹캠으로 촬영한 사진 한 장을 처리한다. `--image`는 터미널에서 예측을 점검하는 옵션으로, 블러 미리보기와 Grad-CAM은 Gradio 화면에서 확인할 수 있다.

## 5. 검증 범위

두 파일 모두 Python 문법 검사를 통과했다. 고정한 검출 좌표와 테스트용 예측 함수를 사용해 블러 결과가 선택 상자 안에서는 원본 픽셀과 일치하고 밖에서는 전체 사진의 블러 결과와 일치하는지 확인했다. 다중 버전에서는 중복 후보를 제외한 두 얼굴의 crop이 각각 예측 및 Grad-CAM 호출에 전달되는지 확인했다. 실제 학습 가중치, Haar 검출률, Gradio 화면 실행은 이 테스트의 검증 범위에 포함되지 않았다.
