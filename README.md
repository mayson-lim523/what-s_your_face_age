# what-s_your_face_age

얼굴 사진을 입력하면 7개 나이대(0~9세 / 10대 / 20대 / 30대 / 40대 / 50대 / 60세 이상) 중 하나로 분류하는 이미지 분류 모델 프로젝트입니다. (인공지능 4조)

---

## 📌 Git 사용 규칙

### 1. 코드는 모델별 폴더에 정리하기

- 모델마다 **최상위 폴더를 하나씩** 만들고, 그 모델에 관련된 코드는 해당 폴더 안에만 둡니다.
- 다른 모델의 폴더에 있는 파일은 담당자와 상의한 뒤에 수정합니다.
- 여러 모델이 같이 쓰는 코드(데이터 분류·분할 등)는 `설명 & python 코드/` 폴더에 둡니다.

```
what-s_your_face_age/
├── 설명 & python 코드/    # 데이터 분류·분할 등 공통 코드
├── 작은CNN/               # 작은 CNN(4층) — 처음부터 학습
├── ResNet50/              # ResNet-50 — 사전학습 모델 미세조정
├── ConvNeXt/              # ConvNeXt-Tiny — 사전학습 모델 미세조정
└── 개발일지/
```

> 새 모델을 추가할 때도 같은 방식으로 폴더를 하나 새로 만들어 주세요.

### 2. 각자 개발일지에 한 일 기록하기

- `개발일지/` 안에 **본인 이름(영문) 폴더**를 만들고, 자기 개발일지는 그 폴더에만 작성합니다. (예: `개발일지/LIM/`)
- 작업을 한 날에는 개발일지를 **Markdown(`.md`) 파일**로 남깁니다.
- 파일 이름은 `날짜_번호_주제.md` 형식으로 맞춥니다. 번호를 붙이면 작업 순서대로 정렬됩니다.
  - 예: `2026-11-08_01_데이터셋_구성.md`
- 개발일지에는 아래 내용을 포함합니다.
  - **한 일**: 어떤 작업을 했는지
  - **결과**: 실행 결과, 성능 수치 등
  - **문제와 해결**: 발생한 오류와 해결 방법
  - **다음 할 일**

```
개발일지/
├── LIM/
│   └── 2026-11-08_01_데이터셋_구성.md
└── (본인 이름)/
    └── ...
```
